# Public Cutover Scope

A replacement can be VERIFIED while users still receive the legacy default. Record implementation maturity for the replacement and the scoped cutover change using the [existing maturity model](../02_STANDARD/RELEASE_PROMOTION_STANDARD.md); do not introduce another maturity enum. Record the current selector/default separately from maturity.

The normative ordering and parity gate live in the [compatibility standard](../02_STANDARD/COMPATIBILITY_MIGRATION_STANDARD.md). Bind cutover evidence to the proposed candidate and preserve the tested recovery path after the flip.
